# FIVEROX — Астрахань и Астраханская область

[Обзор рынка, лиды и модель продаж](https://locanilia377-commits.github.io/fiverox-astrakhan-market-2026/) · [Личный кабинет](https://locanilia377-commits.github.io/fiverox-astrakhan-market-2026/cabinet.html)

Сайт и интерфейс кабинета размещены на GitHub Pages. Исследовательская таблица доступна из шапки сайта. Рабочая CRM использует отдельную закрытую Google Таблицу: заметки, менеджеры, касания и журнал не включены в публичные файлы.

Кабинет: вход по коду на почту, список и поиск точек, карточка с редактируемыми полями, воронка, очередь действий и журнал. Сервер проверяет право на таблицу в каждом запросе. Формулы сохраняются; изменение карточки и аудит записываются вместе. [Исходники и установка сервера](apps-script/README.md).

## Текущий статус — 13.11.2026

Интерфейс `astrakhan-cabinet-2026-11-13-r3`; сервер `astrakhan-cabinet-2026-11-12-r2`, Google Apps Script версия 2. Сервер и его разрешения не менялись. В предыдущем выпуске 12.11.2026 проверен путь владельца: кнопка основного сайта → email-код → список → карточка → сохранение → независимое чтение Google Таблицы → автор, время и значения до/после в журнале. Эта историческая проверка не заменяет проверку нового интерфейса редактором.

В интерфейсе r3 исправлен сброс этапа и приоритета после «Обновить». Обновление сохраняет фильтры и перечитывает открытую карточку. Пока карточка загружается, её поля недоступны для записи. После обрыва связи кабинет сначала перечитывает фактический результат и затем подтверждает сохранение с прежним ID операции. Восстановление после переноса адресуется перенесённой карточке. Конфликт воронки загружает фактический этап; выход очищает также скрытые данные карточки и список менеджеров.

Исправлена инициализация входа: ошибка почтового сервиса больше не прерывает сохранение конфигурации CRM. Готовность почты проверяется отдельно. Диагностика отправки хранит ограниченный журнал исходов и номер запроса без кодов и токенов. При ошибке отправки сохраняется ответ с номером запроса, а недоставленный challenge удаляется.

В production 12.11.2026 на r2 проверены несколько полей за одно сохранение, ноль и сумма с копейками, буквальный текст, похожий на формулу, сохранность формул, запись касания, перенос в воронке, мобильное сохранение при ширине 390px и отказ при конфликте с прямой правкой Google Таблицы. Анонимные чтение и запись отклонены. Тестовые записи того выпуска удалены; сохранены 203 исходных ID.

Пройдены 14 локальных проверок серверной логики: восстановление после почтовой ошибки, роли, отзыв доступа, выход, ограничения и срок действия кодов, срок сессии, Gmail-алиасы, идемпотентность и атомарная запись. Повторить: `node tests/backend.mjs`.

Для r3 пройдены 10 сценариев в реальном браузере с локальным вымышленным backend: обновление, обрывы до/после записи, повтор касания без дубля, восстановление нужной карточки, конфликт воронки, блокировка формы, поздний ответ после выхода, восстановление на 390px и очистка приватных данных. [Результаты](tests/frontend-browser-qa.json), [повтор проверки](tests/frontend-verification.md). Это локальная проверка интерфейса, не проверка прерывания production-сети. Полный маршрут приглашённого редактора на r3 ожидает проверки после публикации; доступ этому редактору уже предоставлен в закрытом файле.

## Файлы

- `index.html` — существующий рынок, лиды, графики и калькулятор; добавлена ссылка на кабинет.
- `cabinet.html`, `cabinet.css`, `cabinet.js` — интерфейс кабинета без приватных данных.
- `crm-config.js` — URL опубликованного Google Apps Script; серверные секреты здесь не хранятся.
- `apps-script/Code.gs` — сервер с шаблоном ID закрытой таблицы.
- `apps-script/appsscript.json` — сервис Sheets API v4 и необходимые OAuth scopes.
