# Проверка интерфейса на вымышленных данных

Запустить из корня репозитория: `python3 tests/frontend-fixture.py`.
Открыть `http://127.0.0.1:8770/cabinet.html` и панель `http://127.0.0.1:8770/qa`.
Сервер доступен только на loopback. Он не обращается к Google и не отправляет писем. Все карточки, адрес и код здесь вымышленные. Войти с `qa@example.invalid` и тестовым кодом `00000000`.

1. Открыть карточку A с этапом «КП отправлено» и высоким приоритетом. Нажать «Обновить»: значения сохраняются. Установить фильтры, нажать в панели «Изменить A извне» и снова обновить. Фильтры сохраняются, открытая карточка показывает новый этап и приоритет.
2. В панели включить «Обрыв до сохранения». Изменить комментарий и сохранить. Подтверждение успеха не появляется, форма блокируется. «Проверить результат» показывает старое значение. «Подтвердить сохранение» записывает правку. В панели два запроса имеют один operation ID, событие одно.
3. Повторить с «Обрыв после сохранения»: сервер уже хранит новое значение, подтверждение не создаёт второе событие.
4. Включить «Обрыв после касания», записать касание, проверить результат и подтвердить. В истории одно касание; два запроса используют один operation ID.
5. Оставить открытой A, перейти в воронку, включить «Обрыв после переноса» и перенести B. Ошибка называет B; проверка результата открывает B. Подтверждение не создаёт повторную запись переноса.
6. Изменить B извне, затем перетащить её устаревшую карточку. Конфликт не перезаписывает чужой этап; доска загружает фактическое состояние.
7. Включить задержку чтения и открыть другую карточку. Пока ответ не пришёл, поля недоступны для записи.
8. При задержанном чтении выйти. Поздний ответ не открывает кабинет повторно.
9. При фактической ширине 390px повторить потерю ответа и восстановление. Кнопки доступны, горизонтального переполнения страницы нет.
10. После выхода очистились список, карточка, автор, адрес/контакты и список менеджеров. Элементы управления не остаются заблокированными после входа заново.

Результаты наблюдения хранятся в `frontend-browser-qa.json`. Моделирование сети относится только к локальной среде. Проверка реального редактора и native Google Sheets выполняется отдельно на опубликованном сайте; вымышленная роль editor её не заменяет.
