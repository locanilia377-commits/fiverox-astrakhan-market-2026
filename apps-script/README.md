# Сервер кабинета Астрахани

Интерфейс находится на GitHub Pages: `cabinet.html`, `cabinet.css`, `cabinet.js`.
Google Apps Script выполняет проверку доступа, отправку кодов и запись в закрытую Google Таблицу.

`Code.gs` — исходный код сервера. Перед установкой укажите ID собственной закрытой CRM-таблицы вместо `YOUR_PRIVATE_CRM_SPREADSHEET_ID`. Добавьте расширенный сервис Google Sheets API v4 с идентификатором `Sheets`.

Один раз владелец таблицы запускает `setupAstrakhanCrm` в редакторе Apps Script и выдаёт Google разрешения на таблицы и отправку писем. Настройка создаёт журналы и серверный секрет. Секрет хранится только в свойствах проекта, не в репозитории и не в браузере.

Инициализация CRM сохраняется отдельно от проверки почтового сервиса. Если отправка недоступна, настройка возвращает `mailReady: false` и точную причину. Повторный setup сохраняет существующий секрет. Google продолжает проверять почтовое разрешение при обращении к MailApp; это изменение не выдаёт прав вместо владельца.

Публикация: Web app, выполнение от имени владельца, вызов доступен Anyone. Приватные методы требуют действующую сессию с актуальными правами на закрытую CRM-таблицу. Укажите URL опубликованной версии `/exec` в `crm-config.js`.

Менеджер входит через кабинет на GitHub Pages: почта, затем одноразовый код из письма. Владелец файла — администратор, добавленные напрямую редакторы — редакторы кабинета. Доступ по общей ссылке, домену или Google Group не используется для входа.

Сессия хранится в памяти страницы; обновление страницы требует повторного входа. Выход отзывает серверную сессию. Код действует 10 минут, сессия — 12 часов. Есть ограничения отправок и попыток.

Запись использует стабильный ID точки и проверку версии карточки. Изменения, автор, время, значения до/после и ID операции сохраняются одной атомарной операцией Sheets. Повтор той же операции не создаёт дубликат. Вычисляемые ячейки не перезаписываются.

Журнал отражает операции через кабинет. Прямые изменения редактора в Google Таблице могут обходить журнал кабинета.

Открытый репозиторий содержит интерфейс и код с шаблоном конфигурации. Рабочие заметки, история контактов, журналы, коды входа и сессии в него не выгружаются.
